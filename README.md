# 🎯 Quiz Game

A modern and interactive **Quiz Application** built using **HTML, CSS, and JavaScript**.

Test your knowledge with multiple-choice questions, track your score in real time, enjoy animated progress updates, sound effects, and view your final results at the end.


```bash
cd quiz-game
```

Open:

```plaintext
index.html
```

in your browser.

---

## 🎮 How to Play

1. Click **Start Quiz**
2. Select an answer
3. Score updates automatically
4. Progress bar tracks completion
5. View final score
6. Restart and play again
